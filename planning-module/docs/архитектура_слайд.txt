МОДУЛЬ ПЛАНИРОВАНИЯ ПЕРЕРАБОТКИ ОТХОДОВ (Долгов Е.В.)
Кратко для презентации — 1–2 слайда

────────────────────────────────────────────────────────────
СЛАЙД 1. СТЕК И СТРУКТУРА
────────────────────────────────────────────────────────────

СТЕК
  • Frontend: React 18 · TypeScript · Vite · SPA (nginx в Docker)
  • Backend/API: waste-complex-platform (FastAPI · SQLAlchemy · PostgreSQL)
  • Интеграция: REST /api/v1 (партии, планы, KPI, симуляции, уведомления)

СТРУКТУРА (тонкий клиент)
  planning-module/
  └── frontend/src/
      ├── api.ts           — HTTP-клиент к API платформы
      ├── App.tsx          — вкладки: обзор, Gantt, партии, симуляция
      ├── labels.ts        — подписи статусов (RU)
      └── components/      — GanttChart, KpiCard, PlanPicker, …

  Логика планирования на сервере комплекса:
  waste-complex-platform/api/app/routers/planning.py + services/

ДОМЕННЫЕ СУЩНОСТИ (общая БД комплекса)
  Партия (WasteBatch) → План (SchedulePlan) → Операции (ScheduleItem)
  Линии L1/L2 · маршруты · версии плана · сценарии «что если»

────────────────────────────────────────────────────────────
СЛАЙД 2. ПАТТЕРНЫ И ВЫВОД
────────────────────────────────────────────────────────────

ПАТТЕРНЫ ПРОЕКТИРОВАНИЯ
  • Thin Client / SPA — UI без собственной БД и бизнес-логики
  • Client–Server — React + REST API платформы
  • API Gateway (nginx) — прокси /api на сервер комплекса
  • Separation of Concerns — модуль = представление, платформа = данные и расчёты
  • DTO на стороне API — Pydantic-схемы платформы, TypeScript-интерфейсы во frontend
  • Strategy (симуляции) — baseline / accelerated / emergency
  • State Machine плана — draft → approved → archived (на сервере)

ФУНКЦИОНАЛ МОДУЛЯ (через API)
  Построение сменного плана · перепланирование · Gantt · KPI ·
  уведомления T1/T2 · сравнение сценариев

ВЫВОД
  Модуль — клиентское приложение диспетчера в составе программного комплекса:
  единая БД и алгоритмы на платформе, без дублирования backend. Подходит для
  дипломного прототипа и интеграции с модулями учёта и мониторинга.
