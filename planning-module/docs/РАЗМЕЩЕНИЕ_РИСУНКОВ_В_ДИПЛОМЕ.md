## Быстрый сценарий для скринов (5 минут)

1. Запустить stack: `docker compose -f docker-compose.stack.yml up -d`
2. Открыть `http://localhost:5173`
3. **Обзор** — скрин → Рис. 7  
4. **Новый план** (8 ч) → **Расписание** → скрин → Рис. 8  
5. **Симуляция** → «Аварийный» → скрин с таблицей → Рис. 9  
6. **Уведомления** → «Проверить риски» при необходимости → скрин → Рис. 10  
7. **Утвердить план** (для демо интеграции — отдельно, в eco под manager@eco.local)
