# Общая база данных проекта

Веб-модуль отчётности — **клиент** единой платформы. Все учётные данные хранятся на сервере:

`http://178.57.217.79:8080` (PostgreSQL `waste_complex`).

## Кто что пишет в общую БД

| Модуль (одногруппники) | API-префикс | Данные |
|------------------------|-------------|--------|
| Учёт поступления | `/api/v1/accounting` | Партии, классификация |
| Планирование | `/api/v1/planning` | Планы, линии |
| Мониторинг | `/api/v1/monitoring` | Этапы переработки |
| **Отчётность (этот Django-проект)** | `/api/v1/reporting` | Дашборд, операции, измерения |
| Справочники | `/api/v1/core` | Организации, виды отходов |

## Что не дублировать локально

- Не запускайте `seed_demo` — он не создаёт данные в SQLite.
- Не редактируйте Organization / WasteType / Movement / Measurement в Django Admin — модели отключены от админки.
- Демо-пользователи: `python manage.py setup_roles` (регистрация на **сервере**).

## Локальный файл `db.sqlite3`

Только служебное: сессия, JWT после входа, привязка роли к меню Django.

## Вход

Email и пароль проверяются на сервере: `POST /api/v1/auth/login`.

- `admin@eco.local` — справочник отходов (чтение с API)
- `ecologist@eco.local` — операции, измерения, экспорт
- `manager@eco.local` — дашборд KPI

Пароль по умолчанию: `eco2026`
