# BPMN модуля ECO (основные бизнес-процессы)

Четыре сквозные диаграммы для раздела **2.2.1** диплома — по одному процессу на рисунок, в нотации BPMN 2.0.

| Файл | Процесс | Рисунок (пример) | Исполнитель |
|------|---------|------------------|-------------|
| `eco-bpmn-p01-auth.bpmn` | **P-01** Аутентификация через API | 2.1 | Любой пользователь |
| `eco-bpmn-p08-data-control.bpmn` | **P-08** Контроль качества данных | 2.2 | Администратор |
| `eco-bpmn-p14-export-journal.bpmn` | **P-14** Просмотр и экспорт журнала операций | 2.3 | Эколог |
| `eco-bpmn-p17-measurement.bpmn` | **P-17** Создание экологического измерения | 2.4 | Эколог |

Полный каталог процессов: `docs/БИЗНЕС_ПРОЦЕССЫ_ECO.md`.

## Алгоритм построения

См. **`BPMN_GOST_ALGORITHM.md`**:

- один пул, три дорожки (Пользователь / Веб-модуль ECO / API платформы);
- поток **слева направо**, без «звёзд» меню;
- один старт и конец(ы); шлюзы XOR с подписями «да» / «нет»;
- подписи задач — бизнес-действия, без `GET`/`POST`.

## Текст для § 2.2.1 (кратко)

В подразделе 2.2.1 представлены BPMN-диаграммы **четырёх основных бизнес-процессов** веб-модуля: вход в систему (P-01), контроль согласованности данных (P-08), работа с журналом операций и экспорт (P-14), регистрация экологического измерения (P-17). Остальные процессы (просмотр справочников, дашборды, выход) описаны в таблице 2.1 и в документе `БИЗНЕС_ПРОЦЕССЫ_ECO.md`.
