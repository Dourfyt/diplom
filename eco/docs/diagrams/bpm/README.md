# BPMN модуля ECO

## Для диплома (Word)

| Файл | Подпись к рисунку |
|------|-------------------|
| `eco-bpmn-00-obzor.bpmn` | Общая структура процессов модуля отчётности |
| `eco-bpmn-01-vhod.bpmn` | Процесс входа в систему |
| `eco-bpmn-02-admin.bpmn` | Процесс администрирования |
| `eco-bpmn-03-ekolog.bpmn` | Процесс работы эколога |
| `eco-bpmn-04-otchety.bpmn` | Процесс формирования отчётности |

1. Открыть https://demo.bpmn.io/
2. **Open File** → выбрать `.bpmn`
3. **Export** → SVG (лучше для Word) или PNG
4. Word: **Вставка → Рисунки**, ширина ~15 см

## Не для печати

`eco-all-processes.bpmn` — полная схема, слишком широкая для страницы.
